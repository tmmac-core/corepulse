# Sicherheitslücken melden / Reporting security issues

Bitte melde Sicherheitslücken **nicht** als öffentliches Issue, sondern vertraulich über GitHub:
Reiter **Security** → **Report a vulnerability** in diesem Repository.

Please do **not** open a public issue for security problems. Report them privately via the **Security** tab →
**Report a vulnerability** in this repository.

- Wir antworten innerhalb von 7 Tagen. / We reply within 7 days.
- Unterstützt wird jeweils nur die neueste Version. / Only the latest release is supported.
- Prüfe vor dem Melden, dass deine APK echt ist: Zertifikats-Fingerabdruck in `docs/RELEASE.md`.
  / Before reporting, check that your APK is genuine: certificate fingerprint in `docs/RELEASE.md`.
